# Тренировки — как получить APK

1. Зарегистрируйся на github.com (бесплатно).
2. Создай новый репозиторий (кнопка New), любое имя, Create repository.
3. Нажми "uploading an existing file" и перетащи ВСЁ содержимое этой папки
   (включая скрытую папку .github). Нажми Commit changes.
   Если .github не загрузилась: Add file -> Create new file, в имени напиши
   .github/workflows/build.yml и вставь туда содержимое одноимённого файла.
4. Вкладка Actions -> "Build APK". Подожди 5-8 минут до зелёной галочки.
5. Открой завершённый запуск, внизу в Artifacts скачай trenirovki-apk,
   внутри лежит app-debug.apk.
6. Перенеси APK на телефон, открой, разреши установку из этого источника.

Приложение: всё лежит в www/index.html.
После любых правок файла GitHub соберёт новый APK автоматически.
Важно: новая сборка подписывается другим ключом, поэтому её нужно ставить,
предварительно удалив старую. Перед этим сохрани данные кнопкой
"Данные и сброс" -> "Скопировать", потом восстанови в новой версии.
