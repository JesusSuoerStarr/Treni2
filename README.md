# Тренировки: планер, бег и шаги

Приложение для Android (Capacitor). Всё работает без интернета.

- **Сегодня, План, Мышцы** — недельный планер силовых тренировок.
- **Бег** — запись маршрута, дистанции, времени, темпа и скорости по GPS, в том числе при выключенном экране. Пробежки по дням можно планировать в «План» → «Пробежки по неделе». Маршрут сохраняется в GPX.
- **Шаги** — шагомер на датчике телефона, цель на день, график за 7 дней.
- **Данные** (внизу вкладки «План») — резервная копия в файл или текстом, восстановление.

## Как получить APK

1. Залей файлы в репозиторий (корень, `www/`, `.github/workflows/`), нажми Commit changes.
2. Вкладка Actions → последний запуск «Build APK», подожди до зелёной галочки (5–8 минут).
3. Внизу страницы запуска, в Artifacts, скачай `trenirovki-apk`, внутри лежит `app-debug.apk`.
4. Установи APK на телефон.

Важно: APK теперь подписывается постоянным ключом из `debug.keystore`, поэтому новые версии ставятся поверх старой и данные сохраняются. Первую версию с этим ключом нужно ставить после удаления старого приложения: перед этим сохрани данные («План» → «Данные и новая неделя» → «Сохранить в файл»).

## Для записи бега при выключенном экране

Разреши геолокацию, уведомления и «Физическую активность». В настройках телефона для приложения отключи ограничения батареи («Без ограничений»), иначе Xiaomi, Samsung и Huawei могут остановить запись.
